# Directivas Multi-Agente (Antigravity, Codex y Claude Code)

Este repositorio educativo de **Campuslands** (`campuslands-express-ratelimit-interactivo`) enseña el uso de **`express-rate-limit`** como middleware en **Express.js** con **ECMAScript Modules (ESM)** y una base de datos en memoria basada en un arreglo de **Videojuegos**.

## Reglas de Sincronización con Obsidian y Graphify
1. Antes de editar archivos, ejecutar `git status --short`.
2. Consultar contexto en Obsidian (`memoria contexto campuslands-express-ratelimit-interactivo`) y el grafo en `graphify-out/graph.json`.
3. Al finalizar cambios:
   - Actualizar grafo: `graphify update .`
   - Exportar a Obsidian: `graphify export obsidian --dir "$HOME/Documents/OBSIDIAN/PROGRAMACION/Graphify/campuslands-express-ratelimit-interactivo"`
   - Refrescar memoria: `memoria refresh`
4. Mantener el visor de código estilo **VS Code Dark+** en `index.html` con tokenizador léxico de una sola pasada y salto de línea automático (`white-space: pre-wrap; word-break: break-word;`) sin truncar ni omitir líneas.
